# Supply Chain Logistics Analytics

## 📊 Project Overview

The Supply Chain Logistics Analytics project is a data-driven analytics solution designed to monitor and analyze supply chain performance.

The project analyzes logistics, delivery, inventory, warehouse, revenue, transportation, and risk-related data to identify operational problems and provide actionable business insights.

A Power BI dashboard is developed to provide an interactive view of supply chain performance and predictive delivery-risk analysis.

---

## 🎯 Project Objectives

- Analyze delivery performance
- Identify delayed orders
- Calculate delivery delay rate
- Analyze average delivery delay
- Monitor inventory levels
- Analyze warehouse utilization
- Compare shipping modes
- Analyze transportation costs
- Identify high-risk, medium-risk, and low-risk orders
- Analyze product revenue
- Identify important factors affecting delivery delays
- Provide business recommendations using data analytics
